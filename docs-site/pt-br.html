Conecte projetos, decisões e fontes. Consulte o grafo com Cypher e recupere os registros que explicam como uma decisão foi tomada.

Escolha como rodar

Use dados de exemplo no primeiro teste. O Brainwire está em beta experimental.

Docker para o servidor

Use Git, Docker e Compose para iniciar o servidor Bolt e acessar o grafo com Python ou com a interface de terminal. O volume do Docker preserva os dados entre reinícios. A imagem pública pode ser baixada sem login.

Ver comandos do Docker →

CLI local no macOS ou Linux

Compile o binário e rode Cypher diretamente em um diretório do RocksDB. Essa opção dispensa Docker e servidor. Cada diretório pode ser aberto por um processo por vez.

Como ler o benchmark

A comparação histórica usa três execuções por banco, com 1 milhão de nós e 2 milhões de arestas por execução. Os contêineres tinham limite de 2 CPUs e 3 GiB cada. O gráfico mede uma compilação local da v0.20.0-beta.2.

Compare criação de nós, criação de arestas e tempo de recuperação como etapas distintas. Os bancos usaram protocolos e configurações de durabilidade diferentes. O teste não mediu o pico de memória.
