# Brainwire identity

The symbol is a connected six-node network. The wordmark uses outlined letters,
so these SVGs do not load a font or make network requests.

- `brainwire-logo.svg`: light wordmark for dark backgrounds.
- `brainwire-logo-light.svg`: dark wordmark for light backgrounds.
- `brainwire-icon.svg`: compact mark on a dark surface, including favicon use.

Keep space around the symbol and use the icon when the full wordmark becomes
too small. Avoid glow effects and gradients. The primary green is `#49E86D`;
use `#0B0F0D` for dark surfaces and `#EDF5EF` for light text.

The wordmark artwork is set from Geist 1.800 at weight 650 and converted to
paths. Font copyright: 2024 The Geist Project Authors. Geist is licensed under
the SIL Open Font License 1.1; no font files are distributed in these assets.
