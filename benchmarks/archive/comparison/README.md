# Historical comparison receipts

This directory preserves raw data from early synthetic comparisons. Those
results apply to their recorded fixtures, binaries and environments. They do
not rank the current release or establish a production service level.

The older comparison narrative and charts were removed from the documentation
because they are stale. Raw receipts and runner history are retained unchanged
for auditability. Use the [current benchmark guide](../../../BENCHMARKS.md)
and [result index](../../../docs/benchmarks/README.md) to evaluate a new candidate.
