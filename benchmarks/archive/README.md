# Historical benchmark artifacts

This archive holds older synthetic benchmark runners, receipts and screenshots.
Recorded data is preserved unchanged; it describes its original source, binary,
dependencies and host. It does not qualify the current release.

Use [current benchmark guidance](../../BENCHMARKS.md) and the
[results index](../../docs/benchmarks/README.md) for current evaluation.
Archived Python scripts may depend on historical packages. Read the recorded
conditions before rerunning them; a run with today's dependencies is a new result.
