# Experimental quorum qualification — October 13, 2026

Python commands below use the environment from [Python setup](../python-package.md).
These commands use the current checkout's Python dependencies. They do not
recreate the historical dependency environment; original versions remain in the receipts.

An opt-in fixed three-voter OpenRaft 0.9.25 protocol now serves Brainwire
Bolt/Cypher transactions. See the [operations guide](../quorum-replication.md).
This report covers isolated native processes and synthetic data on one host;
it does not qualify Kubernetes/Swarm, physical machine loss or production HA.

## Candidate and evidence

The final debug binary is `target/quorum-final-20261013/brainwire`, with SHA-256
`ffd228769250700adb182ad6f1064ecb66e93581e0b91ad9fbcaa3d16c241cd5`.
Its base commit is `5900987`; the accompanying source manifest binds the new
Cargo/Rust files and fault harness independently of the eventual commit ID.
There is no throughput or release-image performance claim for this debug build.

The machine-readable receipts are in [the evidence directory](2026-10-13-quorum/).
`acceptance-200-source-final.json` is the final candidate run. Earlier PASS runs
are intermediate candidates; the unsafe erased-voter experiment remains a FAIL
receipt and is not included in supported acceptance.

The fault suite checks two named graphs and 200 synthetic indexed nodes,
private node ACL, import cursors, follower refusal, majority election after a
symmetric leader partition, stale transaction refusal, leader death after
acknowledgement, majority loss, explicit request-identity deduplication, retained
state restart and equality of all eleven column-family logical digests on all
three members. Missing graph, consensus directory, registry and identity each
refuse startup; restoring the original retained files permits catchup.
The lost-ACK scenario intentionally ignores a successful response; it does not
inject a packet drop precisely at COMMIT. The request outcome is durably recorded.

The final workspace run passed **614 tests**, with zero failed or ignored tests;
Clippy with warnings denied, formatting and diff checks also passed. Source and
check-log hashes are bound by `candidate.json`, `checks.json` and `verify.py`.

Unit/integration tests cover durable votes/logs, committed/applied crash ordering,
deduplication, bounded transport, peer identity and mTLS certificate failures.
Selected OpenRaft storage-suite contracts pass; the entire suite is not claimed
because snapshot/purge operations are deliberately unsupported.

## Reproduce

```sh
cargo test --workspace --locked --offline
cargo clippy --workspace --all-targets --locked --offline -- -D warnings
cargo fmt --all -- --check
.venv-brainwire/bin/python crates/server/tests/quorum_replication.py \
  --binary target/quorum-final-20261013/brainwire --rows 200
python3 docs/benchmarks/2026-10-13-quorum/verify.py
```

The harness creates and removes its own directories, ports, proxies and child
processes. It never uses external application data or existing containers. A full-suite first
attempt encountered a pre-existing Bolt authentication-deadline test timing
failure while a compiler was running concurrently; the final suite is run with
`RUST_TEST_THREADS=1`, retaining the original assertion and deadlines.

## Remaining limits

Three fixed voters require two durable members for progress. Followers do not
serve user queries. All graph copies are complete; no sharding is implemented.
Snapshots, log compaction, dynamic membership and safe replacement of an erased
voter are pending. The retained-log byte cap fails closed; it is not a compactor.
Never erase a voter's persistence and reuse its identity. Restart uses the entire
original volume, including identity, consensus state, registry and graph stores.

Peer mTLS is required outside loopback. Native Bolt TLS is still pending; its
existing protected proxy boundary remains separate. Authentication policy files
must be consistent across members. Static membership, schema evolution, rolling
upgrades and three-machine deployment need separate qualification. Archived
standalone candidate receipts remain bound to their original binaries/images.
