# ACL-filtered Cypher reads on 100k nodes — October 15, 2026

One release-mode run on a fresh synthetic graph with 100,000 `Customer` nodes.
Every node has private ACL metadata, alternating between Alice and Bob. The
queries execute as Alice and validate exact visible counts. Each result is the
median and maximum of seven warm samples after one warmup.

| Operation | Visible rows | p50 | max | Peak query reservation |
|---|---:|---:|---:|---:|
| Indexed equality count | 7,143 | 33.650 ms | 38.083 ms | 5.8 KiB |
| Full label count | 50,000 | 149.760 ms | 150.659 ms | 5.5 KiB |
| Visible property count | 50,000 | 221.571 ms | 223.517 ms | 5.6 KiB |

The timing includes transaction begin, ACL policy evaluation, query execution and
read transaction commit. It excludes graph construction and database reopen.
The import took 611.692 ms in this run. Reservation is query accounting, not
process RSS. These are warm, embedded, single-process timings; they do not
qualify networked server latency or quorum throughput.

Reproduce with:

```sh
cargo run --release --locked --offline -p brainwire-cypher \
  --example acl_reads -- 100000
```

The [raw JSON receipt](2026-10-15-acl-reads-100k.json) contains individual
samples and the exact query/configuration values.
