# Synthetic integration diagnostic: v0.15.0-beta.15

A local 2 GiB container loaded 200,000 nodes in 20 labels and 200,040
relationships, then exercised incremental updates, deletes and an abrupt
restart using an external Python application writer. Counts and the offline
index audit passed. The writer and fixture are external to this repository;
this is an integration receipt, not a standalone reproducible benchmark.

On a single warm connection, 200 sequential point lookups after 20 warmups
had median/p95 of 1.054/1.355 ms for an ID projection and 1.162/2.240 ms for
a full node, including client round trip. An earlier instrumented run, which
failed later due to a test-script cleanup bug, recorded 9.899/55.451 ms for
the projection. This variability and the shared host preclude a performance
claim or SLO. Synthetic properties were highly compressible. Neither run
qualifies production memory or multi-machine failover.
