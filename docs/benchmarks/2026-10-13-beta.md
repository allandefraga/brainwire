# October 13 beta qualification

This session qualifies the supported local single-node path, using disposable
synthetic graphs and private test credentials. It does not certify the complete
requested product, an existing external application deployment or multi-machine replication.
The [quickstart](../mvp-quickstart.md) and [remaining beta queue](../2026-10-pilot-roadmap.md)
describe how to use the candidate and what still blocks a production decision.

## Behavior added

- Independent requested-owned PackStream allocation budgets before reserve,
  minimum remaining encoded elements and fallible exact allocations. Decoded
  allocations are separate from the encoded request cap and engine query pool.
- A default 300-second complete-request IO deadline after authentication. Partial
  bytes and NOOPs do not renew it; completed responses begin the next deadline.
  IO failures close the session and discard pending transaction state. Blocking
  synchronous engine execution is excluded; results remain materialized.
- Responses are encoded and written one frame at a time, avoiding an additional
  aggregate encoded response vector. This is not a streaming Cypher executor.
- Default connected Ontology/Memory/Indexes/Graph workspace, lazy pane loading,
  preserved selection, manual refresh and navigable permission/stale errors.
  Graph checks typed source existence and outgoing neighbors in one READ
  transaction; it returns 20 rows plus a further-row marker, not total degree.
- Strict Python `bolt+s` certificate/hostname checks through a single-host TLS
  proxy. Proxy/native idle boundaries require client pool liveness; current
  Python producers use a 30-second threshold below proxy 60/native 300 seconds.

The native load process was sampled on macOS; residency can reflect OS compression
and reclamation as well as application allocation. The trace alone does not prove
absence of leaks or impose a heap/RSS bound. The high-degree timing returns only

counts input rows, while comments additionally create edges. Different fixture
shapes, candidate hashes and concurrent host work prevent a comparative speedup claim.

## Reproduce the final rehearsal

Build once, then keep that binary fixed through all receipts. Source tests use
cached DuckDB 1.5.5 DuckLake/sqlite extensions and Neo4j driver 6.3.0. Every harness
creates disposable local storage; TLS additionally needs Docker and its local
candidate image. Run from the repository root:

```sh
uv run --no-project --with neo4j==6.3.0 python docs/benchmarks/2026-10-12-auth/mixed_load.py --rows 100000 --seconds 3600 --hot-reads > docs/benchmarks/2026-10-13-beta/mixed-100000-3600.json
uv run --no-project --with duckdb==1.5.5 --with neo4j==6.3.0 python docs/benchmarks/2026-10-13-beta/rehearse.py
python3 docs/benchmarks/2026-10-13-beta/verify.py --self-check
python3 docs/benchmarks/2026-10-13-beta/verify.py
uv run --no-project --with matplotlib==3.11.2 python docs/benchmarks/2026-10-13-beta/plot.py
```

The runner requires a complete passing hour-load receipt before starting, then
executes DuckLake, import recovery/restore, multigraph and neighborhood scenarios
sequentially. It promotes the older DuckLake harness's completed report only after
successful process exit. On timeout it interrupts only the owned child process
group, including its native server; forced interruption is a failed rehearsal.

These commands reproduce the final load/source phase; other receipt rows have
separate executable harnesses linked from their guides. The collector remains
standard-library-only; Matplotlib is used only for the trace figure and Pillow
only for full PNG decode evidence. Rebuilding to a different native/image identity
requires a new dated candidate folder and matching receipts rather than editing
these frozen hashes. Source extensions must already be cached.

## Qualification limits

Synthetic localhost observations are not comparative speedup claims or production
SLOs. Mixed writes are deliberately throttled; RSS is sampled approximately every
five seconds and may miss peaks. Allocation quotas bound requested-owned storage,
not allocator overhead, total process memory or aggregate connections. The source
bridge measures input rows, not total node/edge mutations. DuckLake is an explicit
local SQLite version-pinned snapshot, not CDC or a production catalog/backend.

Native TUI TLS, immediate cancellation, graceful drain, bounded streaming results,
real external application data/queries, replicated failover, ANN/text search, history/retention,
object-storage recovery and published documentation remain unqualified. Existing
Kubernetes/Swarm packaging preserves one active retained-store owner; replicas
and load balancing alone do not create a distributed database.
