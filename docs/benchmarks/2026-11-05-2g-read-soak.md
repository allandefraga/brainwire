# 2 GiB read soak on beta.12

A 30-minute synthetic read diagnostic on the published `v0.15.0-beta.12`
image used a 2 GiB container, 100,000 nodes and 100,000 relationships with
ACLs. Four readers ran after the initial write load. Exact final counts and
the offline store audit passed; no OOM was observed in cgroup/Docker evidence.
During the read phase the sampled process RSS peaked at 248,807,424 bytes;
cgroup working-set samples and page cache are different measures. The
container and volume created by the test were removed.

This is a shared Docker Desktop host, not an isolated Linux production host;
kernel logs were not independently verified. The dataset and reads are synthetic,
the write load was not sustained during the timed phase, and the image predates
beta.13. This observation is neither a hard RSS ceiling nor qualification for
2/4/8 GiB production workloads.
