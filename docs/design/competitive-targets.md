# Product evaluation targets

Evaluate Brainwire against application needs using the same data, query shapes,
permissions and durability requirements. Product superiority has not been
established.

Priorities are predictable memory pressure behavior, durable writes and
reconciliation, useful indexed queries, explicit ontology metadata, bounded
context for agents and recovery that operators can verify.

Use the [production roadmap](../production-readiness-roadmap.md) for remaining
work and [benchmark methodology](../../BENCHMARKS.md) for measured evidence.
